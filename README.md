# Pathfinding Visualizer

An interactive pathfinding visualizer for exploring how search algorithms navigate a grid, compare routes, and respond to obstacles.

## Planned Features

- Grid-based pathfinding visualization
- Breadth-first search, depth-first search, Dijkstra, and A* search
- Walls, weighted cells, and adjustable animation speed
- Random grid and maze generation

## Development

```bash
npm install
npm run dev
```
